# 💼 Job Application Tracker

A responsive web application designed to help users organize job applications, manage company details, track interview dates, and monitor application progress.

## 🚀 Features

- Add job applications with company and job role details.
- Record application dates.
- Add optional interview dates.
- Track application status:
  - Applied
  - Interview
  - Selected
  - Rejected
- Edit existing application details.
- Delete applications.
- Search by company name or job role.
- Filter applications by status.
- View application statistics.
- Automatically save application records using browser Local Storage.
- Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application functionality.
- **Local Storage** – Saving application details in the browser.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Add your job application details.
5. Edit, search, filter, or delete applications.

No backend installation is required.

## 🌐 GitHub Pages Deployment

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.

Your website will be published using GitHub Pages.

## 💾 Data Storage

This project uses browser Local Storage. Application records remain in the browser on the device where they were entered. They are not uploaded to a server or synchronized across devices.
